The working loop

From physical input to a reviewed local action

Each stage stays visible. Nothing has to disappear into an opaque “automation” button.

1

Capture or create

Record real keyboard and mouse input, or start with a blank macro and insert commands from the palette.

2

Inspect the rows

Adjust timing, keys, coordinates, loops, variables, and notes in a readable instruction grid.

Delay · KeyDown · KeyUp

Bind and constrain

Choose fire-once, hold-to-run, or repeat-while-held, then optionally filter by window title or process.

Ctrl + Alt + F9

Run and verify

Keep the engine on, trigger the hotkey in the target application, and review the local run log.
